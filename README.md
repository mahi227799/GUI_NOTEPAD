# GUI Notepad

A simple desktop Notepad application built with Python and Tkinter.

## Features

- Create a new text file
- Open existing `.txt` files
- Save text files
- Cut, copy, and paste text
- Scrollable text editor
- Keyboard shortcuts
- Simple About dialog

## Technologies Used

- Python
- Tkinter

## Keyboard Shortcuts

- `Ctrl + N` — New file
- `Ctrl + O` — Open file
- `Ctrl + S` — Save file
